AI Krew 메시지 vs 모먼트 직접 운영 메시지

모먼트 직접 운영은 카카오비즈니스 가이드(모먼트 화면 기준), AI Krew는 AI Krew 스쿼드 위키만 근거로 비교

요약

할 수 있는 범위는 모먼트 직접 운영이 더 넓고, 작성 편의는 AI Krew가 앞섬
  • AI Krew는 채널메시지 기본 기능 위주로 지원: 유형 4/8종, 발송 대상 3/4종, 타겟 항목 일부, 랜딩은 URL만
  • 이벤트 친구, 메시지 최적화, 새 친구 추가 발송은 AI Krew 위키에 언급 없음
  • AI Krew에만 있는 기능: 구성안 추천, 문구·이미지 방향 추천, 등록 전 사전 검수, 예상 비용·잔액 자동 확인
  • 실행 가능 상품은 채널메시지만. 개인화·브랜드·브랜드픽 메시지는 추천까지만

상세

메시지 유형

  • 모먼트 8종: 기본 텍스트, 와이드 이미지, 와이드 리스트, 캐러셀 커머스, 캐러셀 피드, 프리미엄 동영상, 카탈로그, 스포트라이트
  • AI Krew 지원 4종: 기본 텍스트, 와이드 이미지, 와이드 리스트, 캐러셀 피드
  • 나머지 4종은 모먼트에서 직접 생성하도록 안내
AI Krew 위키에는 미지원 유형이 "나머지 4종"으로만 적혀 있어, 이름은 가이드의 8종과 대조해 채움

만들기

  • 구성요소 규격(가이드): 기본 텍스트 내용 1,300자·줄바꿈 99회, 와이드 이미지 내용 76자, 와이드 리스트 최대 5개, 캐러셀 피드 카드 최대 6개·홍보문구 180자, 카탈로그 아이템 3~7개, 버튼명 8자
  • AI Krew 위키에는 글자수 기준이 별도로 없고, 입력값 검증 단계만 있음
  • AI Krew 미지원: 동영상, 쿠폰·예약 소식 첨부, 공유하기, URL 외 랜딩, 메시지 최적화
  • AI Krew 추가 기능
    • 핵심 요소만 받고 자주 쓰는 조합으로 구성안 최대 4개 제안
    • 문구 추천, 이미지 방향 추천
    • 등록 전 오탈자·규격·금지어·금지 이미지 점검, 광고성·연령인증 1차 판단

발송

  • 발송 대상: 모먼트는 이벤트 친구(내 광고 클릭·픽셀 이벤트 발생 친구, 40원)까지 4종, AI Krew는 이벤트 친구 없음
  • 직접 설정 타겟
    • 모먼트: 맞춤타겟(최대 10개), 성별, 연령, 지역(전국·국내+해외·시/도), 카카오쇼핑, 관심사·업종, 친구 기간, 디바이스, 예산(반응률 높은 순 / 랜덤)
    • AI Krew: 맞춤타겟, 성별, 연령. 지역은 전체 고정
  • 새로 추가되는 친구에게도 발송(최대 31일): 모먼트만
  • 발송 시간: 둘 다 20:55~익일 08:00 발송 불가
  • 분산 발송(100~2,000건)·푸시 끄기: 둘 다 가능
  • 전환 추적: 픽셀 1개 설정은 동일. AI Krew는 연동 픽셀이 여러 개면 사용 중인 픽셀 위주로 3개까지 추천
  • 테스트 발송: 둘 다 친구인 번호로만, 30초에 1회
  • AI Krew는 예상 모수·비용·잔액 자동 안내, 잔액 부족 시 중단 후 충전 안내

AI Krew 상품 범위

  • 채널메시지(새 메시지 만들기 방식): 만들기·수정·발송·종료까지 실행
  • 예전 방식(캠페인→광고그룹→소재 구조) 메시지: 조회만
  • 개인화·브랜드·브랜드픽 메시지: 추천만 하고 모먼트로 안내

베타 관련 참고

  • 베타 사용자는 대행사 마케터 → 원하는 구성을 지정해 요청할 것으로 보고, 11/10부터 지정 구성 그대로 반영하도록 변경 중
  • 메시지 비중이 큰 베타 계정 1곳이 메시지 전부에 공유하기 사용 → 공유하기 추가 논의 중

출처

  • 모먼트 직접 운영(카카오비즈니스 가이드): 메시지 등록, 메시지 발송 설정, 제작 가이드
  • AI Krew(AI Krew 스쿼드 위키, 사내 로그인 필요): Message 광고 생성, 메시지 만들기, 메시지 발송, 테스트 발송, 에이전트 응답 UI, 구성안 개선 논의, 공유하기 논의
  • 별도 참고(개발자 API 문서): 메시지광고 관리, 메시지광고 운영
